# Book Management REST API

A beginner-friendly REST API built using Node.js and Express.js for managing books with CRUD operations.

## Features

* Get all books
* Add a new book
* Update a book
* Delete a book

## Technologies Used

* Node.js
* Express.js
* Postman

## API Endpoints

### GET all books

GET /books

### Add a new book

POST /books

### Update a book

PUT /books/:id

### Delete a book

DELETE /books/:id

## How to Run the Project

1. Install dependencies

npm install

2. Start the server

node server.js

3. Open browser

http://localhost:3000

## Testing

API endpoints were tested using Postman.
